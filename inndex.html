# نُظُم (Nuzum) — Smart Arabic Nutrition & Meal Planner

A modern, minimalist, RTL-first Arabic web application for daily meal planning, macro calculation (BMR/TDEE), food comparison, and automated grocery list generation.

## Features
- **Smart TDEE & Macro Calculator**: Mifflin-St Jeor formula with customizable macro presets.
- **Interactive Meal Planner**: Categorized daily tracking with searchable Arabic food database.
- **Visual Analytics & Comparator**: Chart.js macro breakdowns and side-by-side food nutrient comparisons.
- **Smart Grocery List**: Auto-aggregates ingredients from planned weekly meals.
- **Zero-Build Architecture**: 100% self-contained single-file app ready for GitHub Pages.

## Live Deployment
Enable **GitHub Pages** in repository `Settings > Pages > Branch: main / (root)`.
